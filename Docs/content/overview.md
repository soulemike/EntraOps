EntraOps is a PowerShell module and GitHub repository template to collect, classify and monitor
privileged access across Microsoft Entra ID, Azure RBAC, Microsoft Intune, Microsoft Defender XDR
and Identity Governance - based on Microsoft's [Enterprise Access Model](https://learn.microsoft.com/en-us/security/privileged-access-workstations/privileged-access-access-model).
This documentation covers everything beyond the project overview in the
[README](https://github.com/Cloud-Architekt/EntraOps#readme): how to get started, how the module is
organized, how to customize every part of it, and what changed in every release.

Pick a feature area below to dive in, or start with the **Get Started** guide if this is your first
time setting up EntraOps.
