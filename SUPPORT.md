# Support Policy

EntraOps is a community project provided under the MIT License. It is maintained on a best-effort basis.

The project does not provide a service-level agreement, guaranteed response time, guaranteed remediation schedule, or commercial support commitment. Operators remain responsible for evaluating EntraOps, its permissions, its configuration, and every automated change in their own tenant.

## Community Support

Use GitHub Issues for reproducible defects, feature requests, and documentation corrections. Search existing issues before opening a new one and include the EntraOps version, PowerShell version, execution environment, sanitized logs, and steps to reproduce the behavior.

## Security Reports

Do not report vulnerabilities through public GitHub Issues. Follow [SECURITY.md](./SECURITY.md) instead.

## Microsoft and Other Services

For support for Microsoft Entra, Azure, Microsoft Graph, GitHub Actions, Microsoft Sentinel, or other third-party services, use the support channels offered by the applicable provider.
